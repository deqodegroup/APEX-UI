# STORM UI Integration

## Role of this fork
This DEQODE fork preserves the complete APEX-UI upstream as the visual interface foundation for STORM.

We are keeping the repository whole and adapting it from the fork, in line with DEQODE's upstream-first rule.

## Preserve
- Orb state system
- Particle core
- Reasoning web / agent constellation
- Status bar
- Accessibility behavior
- Reduced-motion support
- MIT attribution and CREDITS

## Replace for DEQODE
- APEX product name and branding
- Reznikov-specific presentation copy
- Golden/cyan visual treatment where it conflicts with STORM/TOP design
- Static demo state cycle with real runtime state from STORM
- Demo roster with real DEQODE agents/tools

## STORM visual direction
- Apple-like Liquid Glass
- White / premium blue base for TOP Lite
- Thin line-art TOP identity where appropriate
- Living centre orb that visibly transitions through idle, listening, thinking, speaking, acting and error states
- ChatGPT-like conversation workspace with voice as a first-class interaction

## Runtime contract
APEX-UI must not become a second intelligence stack.
It is the visual layer. Runtime state and tool events come from the STORM/JARVIS system.

## First product target
TOP Lite for Vagahau Niue.
